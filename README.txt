TOON STUDIO - ANDROID APP PROJECT

Easiest (free, no coding): build with GitHub
 1. Create a free account at github.com and make a new repository.
 2. Upload ALL files of this folder (keep the .github folder).
 3. Open the Actions tab, run "Build APK", wait about 4 minutes.
 4. Download "ZaitoonStudio-APK", unzip, copy app-debug.apk to your phone and open it.
    (Allow "install unknown apps" when Android asks.)

Alternative: Android Studio (free) -> Open this folder -> Build > Build APK(s).

Needs Android 10 or newer and internet on first use (3D engine loads online).
Saved videos and files go to Downloads/ToonStudio.
AI story writing, live rooms and team library only work in the claude.ai version.

Version 1.1: series of episodes, long videos (screen stays on while recording), separate .glb files per character, vertical 9:16, background video, 4 character looks, 5 settings.
Version 1.2: animated .glb characters (idle, talk, wave, jump, dance) for your own app.
